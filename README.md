# Mahesh JEE Classes Website

A modern, responsive landing page for **Mahesh JEE Classes**, designed to showcase personalized JEE coaching programs, teaching methodology, student achievements, and contact information.

## Features

* Responsive design for desktop and mobile
* Clean and modern UI
* Hero section with call-to-action
* About mentor and faculty profile
* JEE Main and Advanced programs
* Teaching methodology section
* Student achievements and testimonials
* Embedded YouTube teaching videos
* Contact section with Call and WhatsApp integration
* Floating WhatsApp button

## Technologies Used

* HTML5
* CSS3
* Responsive Web Design
* YouTube Embedded Player
